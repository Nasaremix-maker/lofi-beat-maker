# Lofi Beat Maker – Web Edition

A browser-based version of the Lofi Beat Maker that works on **iPhone, Android, and desktop**.

## Features
- Live procedural lofi beats
- Presets (Chill, Rainy Jazz, Dusty Boom Bap, etc.)
- BPM, Key, Swing, Reverb, Vinyl, Filter controls
- Chord instrument & drum pattern selection
- Installable as a Progressive Web App (Add to Home Screen)

## How to put it on GitHub Pages (free)

### 1. Create a new GitHub repository
1. Go to https://github.com/new
2. Name it something like `lofi-beat-maker`
3. Make it **Public**
4. Click **Create repository**

### 2. Upload these files
Upload **all** the files in this folder to the root of your new repository:
- `index.html`
- `style.css`
- `app.js`
- `manifest.json`
- `sw.js`
- `README.md`

(You can drag & drop them on GitHub, or use Git.)

### 3. Enable GitHub Pages
1. In your repository go to **Settings → Pages**
2. Under **Source** choose **Deploy from a branch**
3. Select branch `main` (or `master`) and folder `/ (root)`
4. Click **Save**

After 1–2 minutes your app will be live at:

```
https://YOUR_USERNAME.github.io/lofi-beat-maker/
```

### 4. Install on your phone
- **Android**: Open the link in Chrome → menu → “Add to Home screen” or “Install app”
- **iPhone**: Open in Safari → Share button → “Add to Home Screen”

## Optional: Custom domain later
You can add a custom domain in the same GitHub Pages settings if you want.

## Notes
This is a simplified web version focused on the core live experience.  
The full desktop Python version has many more features (journey mixes, video export, stems, custom samples, etc.).

Enjoy!
